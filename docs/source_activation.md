# 진압원 작동 검증과 이전 실행의 제외

초기 16초 캠페인 `study_20260918T153518_d1aa11b4`는 FDS 종료·시간·출력
검사를 통과했으나, M1/M2의 HRR와 표적 채널이 C0와 동일했습니다.
입력 생성기에서 xmin 전체 OPEN 경계와 진압 노즐 패치가 겹쳤습니다.
이 결과를 진압 방법의 무효성이나 방법 간 동등성의 근거로 사용하면 안 됩니다.

수정 생성기는 세 노즐 패치를 제외한 영역만 OPEN으로 지정합니다.
무개입과 개입 조건에 같은 노즐 기하를 두고, M3 운반 기류와 액적 공급도
동일한 개입 시간에만 작동하도록 설정합니다. 원본 결과는 삭제하지 않습니다.

`native_record`는 화원 연소 확인과 별도로 노즐 진단 채널을 검사합니다.
진단이 없는 이전 개입 실행은 `incomplete`로 분류하며, 솔버 정상 종료만으로
소화 통계에 포함하지 않습니다. 양의 투입량은 지정 시간의 작동 증거가 필요하고,
0 투입량 대조군도 별도의 OFF 판정을 거칩니다. 실제 진단값과 판정 사유는
`campaign.json`의 `records[].intervention_activation`에 저장됩니다.

이 검사는 입력한 진압원이 계산에 적용됐는지 확인합니다. 실제 장치의 방출장,
화학 반응, 소화 성능에 대한 독립 실험 검증을 대신하지 않습니다.
