THEORETICAL FOUNDATION

공통 보존 법칙 (Universal Conservation Laws)

FIRST PRINCIPLES

본 시뮬레이션의 모든 모델(M1~M5 및 드론 동역학)은 임의의 가중치나 성공률 점수를 일절 사용하지 않으며, 다음 고전 연속체 역학의 기본 보존 법칙에서 출발합니다.

질량 보존 (Continuity Equation)

∂ρ ∂t + ∇ · (ρu) = sm

입자 분사 질량 수지: m_emitted = m_delivered + m_evap + m_dep + m_esc + m_airborne
운동량 보존 (Navier-Stokes)

∂(ρu) ∂t + ∇ · (ρu⊗u) = −∇p +∇·τ +ρg +fext

노즐 반력: F_reaction = m_dot · U + ρ A U² (기체 및 입자 항 분리 적분)
VERIFICATION 질량 보존 오차 잔차는 수치 부동소수점 오차 한계 내(< 10⁻¹² kg)에서 0으로 닫힘을 매 단계 검사합니다.
METHOD 1

M1 저주파 음향 유동 (Low-Frequency Acoustics)

M1 ACOUSTICS

균일 매질의 질량·운동량 방정식을 미소 섭동(|u| ≪ c, |ρ'| ≪ ρ₀)에 대해 선형화하면 선형 음향 파동방정식이 유도됩니다. 배플 앞 반구로 퍼지는 음향 강도 보존을 통해 유한 개구 Rayleigh 전이 진폭식을 구현했습니다.

∂2p′ ∂t2 − c2 ∇2p′ =0 , urms(r) = u0 A A+2πr2 , Frad = Pacoustic2c
CODE firelab.physics:_simulate_m1 · firelab.acoustics:plane_wave (1D Staggered FDTD 해)
METHOD 2

M2 공기 와류 링 (Pulsed Vortex Ring)

M2 VORTEX RING

노즐 출구의 비정상 슬러그(Slug) 유동에서 순환 Γ와 충격량 I를 계산하고, 점성 확산 코어 a(t)를 갖는 얇은 와류 링의 Saffman 자기유도 속도를 시간 적분하여 전진 거리를 엄밀히 산출합니다. 공간장은 유한핵 정규화 Biot-Savart 적분으로 형성됩니다.

Uring(t) = Γ4πR [ ln8Ra(t) −0.558 ] , x(t) = ∫0t Uring(τ)dτ
CODE firelab.physics:_ring_parameters, _ring_travel, _ring_velocity
METHOD 3 & 4

M3 수분무 증발 및 M4 에어로졸 수송 (Droplet / Particle Transport)

M3 / M4 PARTICLE

구형 희박 입자군(Lagrangian parcels)에 대해 Schiller-Naumann 항력 상관식을 적용하고, Stokes 완화시간 τ_p에 대한 적분 해석해로 위치를 전진시킵니다. 수분무(M3)는 주변 습도·온도를 반영한 등온 Maxwell d² 법칙에 의해 액적 직경이 감소합니다.

τp = ρpd2 18μg(1+0.15Re0.687) , d2(t+Δt) = max [d2(t)−KΔt,0]
CODE firelab.physics:_particle_transport, _water_evaporation_coefficient
METHOD 5

M5 전도성 와류 및 전기유체역학 (EHD / Conductive Vortex)

M5 EHD / CV

단극성 전하 수송과 Poisson 정전기 결합을 1차원 유한체적법으로 풀며, 공간 전하와 전기장의 상호작용으로 인한 Coulomb 체적력 f_e = qE를 계산합니다. 가공의 가속을 방지하기 위해 공급 전력 기반 속도 증가분 상한을 적용합니다.

∇2ϕ = −qε0εr , J = qugas +μqE −D∇q , fe = qE
CODE firelab.ehd:simulate_ehd, firelab.physics:_simulate_m5
DRONE PLATFORM

드론 6자유도 동역학, 액추에이터 디스크, 열용량 (Flight Dynamics & Thermal)

NEWTON-EULER 6-DOF

로터 추진은 운동량 이론(Actuator Disk)을 통해 유도동력 P = T^(3/2) / sqrt(2ρA)를 계산하고 배터리 방전 장부로 관리합니다. 기체 자세는 쿼터니언 미분방정식으로 단위 노름을 보존하며, 외부 화재 열유속에 대해서는 집중 열용량(Lumped Capacitance) 해석해로 과도 온도를 예측합니다.

mv˙ = TR(q)e3 +Freaction +Fdrag −mge3 , CdTdt = Q˙in −H(T−T∞)
CODE firelab.drone:simulate_mission, firelab.drone_study
